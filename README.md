E-Commerce Ad Copy Generator Microservice

A containerized, full-stack AI microservice built with FastAPI, Docker, and Claude 3.5 Sonnet (Anthropic API) that generates structured, high-converting e-commerce ad copy variations.

Key Features





Full-Stack Architecture: Asynchronous FastAPI backend paired with a responsive HTML/Tailwind frontend dashboard index.html).



Smart Auto-Fallback Engine: Frontend automatically detects live FastAPI backend status and falls back to offline simulation mode if the server is offline.



Containerized Deployment: Ready-to-run Dockerfile and .dockerignore for consistent execution across any environment.



Structured Validation: Enforces strict request/response schemas using Pydantic and enables CORS for seamless browser integration.



Complete Documentation: Includes a full Technical Documentation PDF inside the repository.
